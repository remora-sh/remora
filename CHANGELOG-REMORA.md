# Remora changelog

## 0.1.0 — bootstrap

- Product fork of UniSSH rebranded as **Remora** (desktop identity, docs, compose).
- Added `web/` workspace (vault unlock UI + gateway terminal).
- Added `gateway/` optional WebSocket→SSH service (`remora-gateway`).
- Self-host docs: `docs/self-host.md`, backup/restore scripts.
- Termius parity matrix: `docs/parity.md`; import scaffold + tests.
- Deep link scheme `remora://` registered for macOS bundles.
- Security review checklist for v1.0: `docs/security-review-checklist.md`.

Upstream UniSSH history and protocol details remain in `CHANGELOG.md`.
